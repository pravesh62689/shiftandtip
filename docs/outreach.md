## 2. Reddit Manual Community Engagement Plan

*Rule: 100% manual participation only. Never automate Reddit posts or spam links. Add genuine value and context first, referencing Shift & Tip only when directly answering a specific mathematical calculation query.*

### Target Communities
- **`r/Serverlife`** (350k+ servers): Discussions on unfair tip pools, tip-out percentages, and check discrepancies.
- **`r/bartenders`** (250k+ bartenders): Barback tip-out rates, shift lead cuts, and point-system allocations.
- **`r/KitchenConfidential`** (700k+ cooks): BOH tip sharing legality and kitchen tip-out policies.
- **`r/TalesFromYourServer`** (1.5M members): Service worker wage questions and daily tip accounting.
- **`r/restaurantowners`** (40k+ operators): FLSA compliance, tip-pool manager prohibitions, and 80/20 dual jobs rule.
- **`r/smallbusiness`** (1.8M members): Tipped payroll setup, overtime weighted averages, and W-4 advice.

### Response Blueprint
1. **Identify High-Intent Posts**: Filter for threads asking: *"Is this tip pool legal?"*, *"How should we split tips for 3 servers and 1 bartender?"*, *"Does California have daily overtime for restaurant workers?"*
2. **Answer with Direct Math & Statute**: Quote the exact DOL FLSA rule (e.g. 29 CFR § 531.54) or state labor code. Show the step-by-step breakdown directly in the Reddit comment so the user gets immediate value without clicking.
3. **Optional Helper Link**: Include a footnote: *"If you want to plug in different hours or points, I built an open-source tool at shiftandtip.blogspot.com that handles the rounding and kitchen percentage."*

## 3. Quora Manual Answer Plan

### High-Search Quora Target Questions
1. *"How do you calculate a tip pool in a restaurant with different hours?"*
2. *"Can a restaurant manager legally take a percentage of the tip pool?"*
3. *"How does overtime work for tipped employees who make $2.13 an hour?"*
4. *"What is the difference between daily overtime and weekly overtime in California?"*
5. *"How do restaurants calculate tip-out for food runners and bussers?"*

### Answering Strategy
- **Format**: Structured answers with bold key numbers, bulleted steps, and clear subheadings.
- **Authority**: Cite official DOL Fact Sheets (#15 for tipped employees, #23 for overtime) and IRS Publication 531.
- **Graphic/Table**: Include formatted Markdown tables comparing federal vs state rules.
- **Call-to-Action**: Provide a clean contextual link to the specific calculator tool (e.g., `/2026/12/tip-pool-calculator.html`) as an interactive companion.
