## 2. Evolution & Strictness Audit of scripts/audit-data.mjs

1. **Initial Version**:
   - Parsed `data/raw/dol-minwage.html` using `<div id="[a-z]{2}">` regex splits.
   - Parsed `data/raw/dol-tipped.html` table rows `<tr>` and footnotes `<p id="\d+">` by matching state name.
   - Performed exact numeric matching within each state's slice.

2. **Phase 1 Update (Snapshots Integration)**:
   - Added automated detection of fresh run snapshots in `data/raw/snapshots/` (`dol-minwage-2026-11-24.html`, `dol-tipped-2026-11-24.html`, and `state-<code>-2026-11-24.txt`).
   - Added support for states prohibiting tip credits (`tipCreditAllowed: false`) by searching for `$0`, `0`, or explicit statutory text (`"full state minimum wage"`, `"prohibits tip credit"`, `"no tip credit"`).
   - Scoped search strictly to `combinedText` for that state only (`minText + '\n' + tipText + '\n' + stateSnapText`).

3. **Confirmation of Strict Matching**:
   - Matching has **never been loosened** to global document scans or fuzzy tolerances.
   - Numeric values are formatted to 2 decimal places with strict boundary assertions `(?<![\d.])` and `(?![\d.])`.
   - Matching occurs strictly within the matching state's extracted section.
